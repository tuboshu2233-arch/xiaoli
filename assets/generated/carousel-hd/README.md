# Regenerated carousel images

Generated with the built-in image_gen tool on 2026-11-13, replacing the low-resolution PPT frame crops in the four local carousel demos.

- 3 mountain photographs: 1672 × 941.
- 5 restaurant interiors: 1254 × 1254.
- 3 text-free banner backgrounds: 2172 × 724, 2243 × 701, 2172 × 724.

Original generated PNGs are retained in `source/`. WebP assets preserve the generated dimensions and use quality 96 for browser delivery. No source-frame enlargement is used. Complete final prompts, built-in generation mode, source paths, output paths, and actual dimensions are in `generation-prompts.json`.

Banner headlines/subtitles are live HTML. Restaurant navigation lettering is live HTML with the existing licensed Hugeicons arrows, so the controls are not scaled bitmap text.

These are AI-generated demonstration assets, not photographs of identified real businesses. Motion continues to reference the user's PPT examples; the original PPT images remain available through the reference toggle.
