# 面积图与柱状图共享视角控制

参考用户提供的 2026-11-13 18:00:21 录屏，使用 Three.js PerspectiveCamera + OrbitControls 控制相机，再将已有三维坐标投影为 SVG。默认视角水平，拖动后底座、坐标轴、数据作为同一场景绕中心旋转，不再强制拉平基线；镜头距离和投影中心在拖动时固定，不按每一帧的包围盒缩放。两种图表共用相同控制器。

- 水平可旋转至约 ±85°，俯仰允许接近正面到俯视。
- 输入灵敏度按绘图区高度计算，与已有 3D 饼图采用相同 OrbitControls 规则；无惯性、无自动旋转。
- 顶点、曲面、柱宽、组内／组间空隙仍为原有数据几何；柱侧面和绘制顺序按视角调整。
- 日期拾取改为投影区域判断，兼容近侧面和屏幕顺序反转。
- 重置恢复默认视角；重设尺寸时才重新计算适配距离。

源码：`chart.js`、`orbit-view.mjs`、`scene.js`。`chart.bundle.js` 通过 `components/react-bits` 的 `npm run build` 构建，无运行时 CDN 依赖。Three.js MIT 许可见同目录。
