# 立体环形图交互

共享源码服务于 `pie-3d`（深色实心饼图，内半径为 0）和 `pie-3d-rise`（浅色环形图，内半径为 1.85）。采用本地打包的 Three.js 0.187.0 / OrbitControls，使用示例数据。

- 不自动旋转，不启用惯性。拖拽结束后保持视角。
- 默认所有扇区等高、底面为 y=0。选中时改变实体纵向尺度，底面不移动；环形图高度从 0.48 增至 1.05，饼图增至 0.85。
- 点击扇区或图例选择，重复点击保持选中，切换后旧项回落。所有扇区始终显示，无点击隐藏功能。
- 悬停预览数据；点击固定弹窗；关闭、Esc 或重置可清除选择。
- 动画仅在选择变化时运行，约 420ms；开启减少动态效果时立即切换。
- 弹窗锚定选中实体的顶面，随手动视角更新，并限制在图表区域内。

参考为用户提供的录屏与 RichCharts 两个链接。链接在 2026-11-13 重定向到模板首页，具体交互依据用户录屏与明确要求实现，并非提取对方源代码。

构建：在 `components/react-bits` 运行 `npm run build`。组件原始 React Bits 文件校验保持不变。Three.js MIT 许可附于 `THREE-LICENSE.txt`。

配色沿用双层旋转轮播饼图：橙色 `#bd4c00 → #ffb521`、青色 `#12bdc9 → #23efed`、蓝色 `#2750d9 → #3b70ff`、浅蓝 `#7bcdf5 → #bcecff`。深色案例的第五项延续同系列琥珀色。顶面与侧面均采用沿水平方向插值的顶点渐变，侧面适当压暗以保留体积感；图例同步渐变。

扇区分隔采用固定距离平移的直线切缝，内外等宽；实心饼图的切边在圆心附近相交，环形图的切边连接内外圆弧。

两种图表默认开启 2.5 秒间隔的扇区轮播：逐项选中、增高、更新弹窗，视角保持不动。提供暂停／继续；悬停图形或图例、键盘聚焦、拖拽与页面隐藏期间暂缓；手动选择后重新计时。减少动态效果设置下默认暂停轮播。

画布不透明度为 1。按用户指定的立体面积图质感，改用自定义双面着色器：顶面保留渐变，侧面透明度均匀延续到底，顶沿使用亮色细边与轻微光晕，底面与底沿明确显示。深色背景和淡网格用于显示透叠层次。顶面、侧面、底面的实际 alpha 均直接使用 0.9（90% 不透明度），去除额外透明衰减；启用表面深度写入，阻止背面轮廓无视遮挡直接叠加。数据弹窗、图例及按钮不受影响。

环形图取消浮动数据弹窗，区域名称和营收放在中间镂空处，占比仅保留在图例中。通过三维投影定位中心，再用屏幕空间 HTML 展示；文字仅做二维平移，拖拽视角后仍保持平面正对屏幕。自动轮播、点击与悬停的数据均同步中心内容。实心饼图保留原浮窗。
