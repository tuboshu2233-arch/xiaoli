# 双层旋转轮播饼图 · 开发交付

交付日期：2026-11-03。以 `index.html` 的动态效果为实现与验收参考。

## 如何查看

解压后双击 `index.html`，直接在浏览器查看，不需要安装依赖或启动服务。`preview.html` 是聊天预览的独立导出版，便于对照。

## 文件

- `index.html`：可离线打开的演示页面，引用下面的可读源码。
- `src/markup.html`：组件结构。
- `src/chart.css`：完整样式，均限定在 `#double-ring-carousel` 内。
- `src/chart.js`：绘图、旋转动画、定时轮播及交互逻辑。
- `data.example.json`：接口数据的示例字段，示例代码暂未发起接口请求。
- `preview.html`：原聊天效果导出，包含通用预览容器。

本演示使用原生 SVG + JavaScript，不依赖 ECharts、Vue、React，也不是一份 ECharts option。`index.html` 及 `src/` 不依赖 Codex 或外部 CDN。

## 视觉与交互验收

1. 两层圆环使用同一组人员分类数据与角度；内层是彩色占比，外层是对应类别的半透明标签环。两层不表示父子层级。
2. 默认从“专职网格员”开始播放，按数据顺序每 2500ms 切换到下一类，并循环。
3. 切换时，双层环及外层文字同步旋转，将当前类别的角平分线移动至顶部。走最短旋转路径，过渡为 850ms 的 cubic ease-in-out。
4. 当前类别内圈向外突出 3px，外圈向外突出 2px、透明度提高；圆心名称、人数及百分比同步切换。
5. 分类颜色固定，轮播时不会把全部分类改成同一种颜色。
6. 鼠标移入圆环时暂停后续自动切换，移出后恢复；已开始的过渡会继续完成。
7. 点击图例或扇区可直接切换；键盘聚焦图例时暂停自动切换。右上按钮可手动开始、暂停。
8. 页面进入后台时不运行定时切换，回到前台恢复；系统启用减少动态效果时，默认不自动播放，并取消旋转过渡。

## 数据接入

`src/chart.js` 顶部的 `data` 是当前演示数据，开发接入接口后用真实数据替换，再执行初始化。`data.example.json` 说明同样的数据结构；它不是页面自动读取的配置文件。

```json
{
  "name": "专职网格员",
  "value": 331,
  "colors": ["#bd4c00", "#ffb521"],
  "label": "#a7753e"
}
```

- `name`：显示名称。
- `value`：非负人数；总数与百分比由当前数据计算，不单独传百分比。当前示例合计 484 人。
- `colors`：内圈从左到右的两个渐变色。
- `label`：外圈标签底色，再由选中状态控制透明度。
- `intervalMs`、`transitionMs`：在 `src/chart.js` 顶部修改轮播与过渡时间。

## 项目接入注意

这是可运行的效果源码，尚未接入业务接口。移植到 Vue / React 时，在 DOM 挂载且数据就绪后初始化；数据变化后重新计算总数、角度与当前选中项。组件卸载时需清理 interval、animation frame、ResizeObserver，以及 document / window 上的监听器。

当前源码针对单个组件，使用固定 DOM ID 和 SVG gradient / textPath ID；同页放置多个实例时要为每个实例增加独立前缀。生产接入还需处理空数组、总数为 0、非法数值和小扇区标签过长等边界；当前演示按这四类非零数据制作。

如项目统一使用 ECharts，可根据这里的同角度双环、顶部对齐和 2500ms / 850ms 动效参数重写；普通高亮轮播不会产生本演示的整环旋转效果。
