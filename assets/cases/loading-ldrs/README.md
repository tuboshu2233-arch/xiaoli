# LDRS loading gallery

Official package: ldrs 1.1.9, UI Ball / Griffin Johnston, MIT.
Sources: https://uiball.com/ldrs/ and https://github.com/GriffinJohnston/ldrs.

44 official Web Components are registered from the installed package and bundled locally. Component source is unchanged. The gallery wrapper adds Chinese/English labels, search, color/size input, playback-rate controls and pause/resume. The pause control affects CSS keyframe animations inside each open shadow root; color transitions remain usable while paused. Reduced-motion preference starts paused.

Build from interaction-library/components/react-bits with npm ci and npm run build. LICENSE is retained alongside this page. No external runtime CDN requests are needed.
